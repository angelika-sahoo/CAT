PHONE INSTALLATION
A PWA must be opened from an HTTPS web address before Android can install it properly.
1. Upload every file in this package to one static HTTPS host such as GitHub Pages, Netlify or Cloudflare Pages.
2. Open the resulting HTTPS address in Chrome or Microsoft Edge on Android.
3. Tap the in-app Install app button, or browser menu > Install app / Add to Home screen.
4. Open the app once while online so the offline cache is created.

IMPORTANT
Opening index.html directly from the Android Downloads folder will display the app, but browsers do not generally permit full PWA installation or service-worker offline caching from a local file address.
Progress is stored locally on that phone and browser. Use Data & backup regularly.
